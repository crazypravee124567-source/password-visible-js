# 🔐 Password Toggle

A beginner JavaScript project that shows and hides a password using DOM manipulation — `getElementById`, `input.type`, and `checkbox.checked`.

## 🚀 Features

- 👁️ Toggle password visibility with a checkbox or eye button
- 🔒 Lock icon switches between locked and unlocked state
- 💪 Live password strength meter — Weak / Fair / Good / Strong
- 🏷️ Status badge — shows whether password is hidden or visible

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

---

## 🧠 JavaScript Concepts Used

| Concept | Usage |
|---|---|
| `getElementById()` | Select the input and checkbox elements |
| `checkbox.checked` | Check if the checkbox is ticked |
| `input.type` | Switch between `"password"` and `"text"` |
| `onchange` | Trigger `togglepassword()` on checkbox change |
| `oninput` | Trigger strength meter on every keystroke |
